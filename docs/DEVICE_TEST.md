# 真机验证记录

首次发布时以下项目均为 **待验证**，不要把电脑端测试结果填成真机通过。

记录：手机型号、ROM、Android / API、内核、KernelSU 管理器与内核版本、播放器版本、源应用包名（可隐去私人路径）。

1. 安装模块并重启，手机能正常启动。WebUI 显示「自动恢复运行中」。
2. 用一个实际存在、内含已下载完整视频的小目录建立映射。
3. WebUI 无错误；MX 手动进入映射目录能看到并播放视频，拖动进度正常。
4. 用源应用下载第二个视频，MX 刷新后可见，无复制、无额外视频占用。
5. 尝试从映射路径删除一个专门用于测试的文件，应失败；源路径仍存在。不要拿重要文件作删除测试。
6. 从源路径编辑/删除测试文件，映射视图同步变化。
7. 再添加另一个应用目录，两个映射均可读；名称带中文和空格。
8. 重启并解锁，在 60 秒恢复周期后重新打开 MX，映射仍可读取。
9. 暂停 / 停用 / 移除映射后，入口解除，源视频仍存在。正在播放时可能暂时报告目录占用，停止后重试。
10. 卸载模块、重启后，源目录和视频保持正常。

如失败，保留 WebUI 诊断，写明失败发生在哪一步。不要通过关闭 SELinux、递归 chmod/chown 原目录来掩盖问题。若后台服务名称不同，诊断可能需要补充该 ROM 的媒体服务信息。
